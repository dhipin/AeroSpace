// =========================================================== Description
== Description

// tag::body[]
{manpurpose}

The command is useful when you messed up with your layout, and it's easier to "reset" it and start again.

// =========================================================== Options
include::./util/conditional-options-header.adoc[]

-h, --help:: Print help

--workspace <workspace>::
include::./util/workspace-flag-desc.adoc[]

--sort-by-window-id::
Order the flattened windows by their window ID instead of keeping the tree order.
Window IDs grow with window creation, so the result is a stable order that doesn't depend on the previous layout or on focus.
Useful for scripts that build a layout with `--window-id` commands right after flattening.
